# Belvedere

A first-person puzzle game about sliding the rooms of a house back into place. Made for [GitHub Game Off 2026](https://itch.io/jam/game-off-2026), theme: Shift.

Eight rooms sit on a 3×3 grid with one gap. Pull a room's lever and the whole room slides, with you inside.

Made by Nick Schaefer with AI coding tools.

## Run from source

Needs [Godot 4.7](https://godotengine.org/) with `godot` on your PATH.

```sh
tools/run.sh    # play
tools/test.sh   # headless tests
```

`docs/SPEC.md` is the full design and spoils the puzzles.
